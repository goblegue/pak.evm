# Pak-EVM (Pakistan Electronic Voting Management System)

Pak-EVM is an Object-Oriented Programming (OOP)-based online voting application designed to provide a secure, efficient, and user-friendly digital voting experience. This project focuses on modern election management by integrating secure authentication, QR code generation, database management, offline capabilities, and administrative controls.

## Project Overview
The system streamlines the voting process by enabling:
- Secure user registration and login
- Authentication and authorization management
- Admin dashboard for election monitoring and control
- QR code generation for voter verification
- MongoDB database integration
- Offline database setup for reliability
- Encryption and security through crypto engine
- Email services for notifications and verification
- Structured controllers, repositories, and interfaces following OOP principles

## Core Features
- User Login & Signup System

## Goal
The primary objective of Pak-EVM is to modernize voting systems by ensuring transparency, accessibility, and security while demonstrating strong software engineering practices through modular OOP design.
